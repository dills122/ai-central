# Editorial Method

## 1. Inventory the source

Record names, terminology, numbers, units, dates, durations, modes, implementation details, claims, evidence, limitations, links, and citations before rewriting.

## 2. Diagnose structure

Look for abstract throat-clearing, repeated lessons, mismatched title and form, guides buried inside narratives, conclusions appearing before their evidence, and endings that repeat the opening.

## 3. Calibrate voice

Find several lines that sound like the author. Note sentence length, vocabulary, formality, point of view, opinion, technical explanation style, humor, and punctuation. Match those habits without making every sentence uniformly polished.

## 4. Line edit

For each paragraph ask:

1. What new fact, explanation, or judgment does it add?
2. Does the first sentence do real work?
3. Can a vague noun become a concrete mechanism?
4. Does a sentence merely repeat the previous one?
5. Is the transition necessary?
6. Is prose, a list, a table, or a diagram the clearest form?

## 5. Audit repeated forms

Count paragraph openings, contrast constructions, rhetorical questions, three-item lists, one-line punchlines, punctuation habits, and lesson summaries. Rewrite repeated structures rather than swapping synonyms.

## 6. Compare facts

Confirm that retained values are exact, omissions do not create contradictions, causal language did not become stronger, diagnostic evidence did not become an end-to-end claim, code remains intact, and citations still support nearby prose.

## 7. Read for cadence

Fix long runs of equal-length sentences, paragraphs that all land a punchline, presentation-style transitions, phrases the author would not say, and manufactured conclusions.
